# pyRfactor2SharedMemory
Python library for accessing TheIronWolf's [rF2 Shared Memory Map Plugin](https://github.com/TheIronWolfModding/rF2SharedMemoryMapPlugin) interface for rFactor 2.

## Acknowledgement
This library is based on:
- rFactor 2 InternalsPlugin header file by S397.
- The Iron Wolf's rF2 Shared Memory Plugin: https://github.com/TheIronWolfModding/rF2SharedMemoryMapPlugin

## What's new
This forked version adds cross-platform support, type hints & annotations, standard naming convention, with some features backported from [pyLMUSharedMemory library](https://github.com/TinyPedal/pyLMUSharedMemory).
